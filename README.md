# ViralLens - AI Content Analysis Tool

ViralLens is a Next.js application designed for AI-driven image analysis, content refining, and social media score evaluation.

## 🚀 Features

- **AI Image & Text Analysis:** Evaluates content for potential virality.
- **Content Refinement:** Enhances prompts and post descriptions using AI brains.
- **Deep Analysis Suite:** Detailed visual and textual content breakdown.
- **History & Settings:** Save analysis history and configure custom API keys.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Database:** Drizzle ORM
- **Language:** TypeScript / JavaScript
